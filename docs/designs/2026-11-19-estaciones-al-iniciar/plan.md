# Estaciones al iniciar sesión

Después de identificar al usuario en la oficina o en el portal del cobrador, mostrar una lista de estaciones activas (número y nombre) y señalar la estación de este navegador. Solo lectura. La cuenta puede continuar aunque no tenga una estación, haya varias coincidencias o la consulta falle. Un error ofrece reintentar. La lista no se entrega antes de autenticar ni al consultar un recibo público. La sesión y el cambio entre portales no deben mostrar dos avisos por un mismo ingreso. Una recarga posterior al cierre del aviso conserva el cierre dentro de la sesión.

Consultar el catálogo activo con una proyección mínima autenticada y las referencias públicas de instalación que ya se usan para los recibos. La estación actual requiere una sola coincidencia vigente en el ámbito de la empresa. Si faltan datos locales o hay varias coincidencias, no elegir a ciegas; distinguir esos estados. Evitar exponer licencias, claves, identificadores de dispositivo o datos de otras sesiones. Consultar con memoria/archivo y con PostgreSQL usando la misma regla vigente. El listado de administración muestra al lado del nombre la columna «Método de facturación» tomada del formato de recepción persistido (Común / Haitiano; histórico sin valor = Común). Se mantiene el formato común para quien envía.

Probar con ejemplos ficticios las dos preferencias, el catálogo vacío, vínculos únicos, múltiples, inactivos o revocados, acceso sin sesión, recuperación de errores y el recorrido por ambos portales. Preparar PR separados a main y demo para fusión de Rardiel.
